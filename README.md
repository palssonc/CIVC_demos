# CIVC Classroom Demos

A static GitHub Pages site for interactive classroom demonstrations.

## Run Locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Project Structure

Each demo should be self-contained under `src/projects/<project-id>/`.

The first demo is `src/projects/declaration-nlp/`, an NLP clustering activity using the grievances from the Declaration of Independence.
